What this is

Two libraries, one language

01 / 13

Every screen in the Altametrics restaurant workforce platform is assembled from two coordinated Angular libraries that share the same tokens, accessibility contract and theming model.

Fn* · fn-*

foundation

The generic UI kit. Imported per-feature module — never the whole library.

  • FormsButton, input, select, switch, pickers, rating & more — 12 controls
  • DataPrime table, editable grid, pagination, charts
  • Nav · feedbackTabs, breadcrumb, accordion, dialog, drawer, toast
Hw* · hw-*

hw-foundation

The HW-branded application shell wrapping foundation in product chrome.

  • ShellApp header: site, profile, apps, weather, time-clock
  • PlatformAuth shell, app market, employee, franchise
  • CommsRelease notes, connect, notifications

How to use

Rules for engineers & agents

13 / 13
01

Import from the alias

Pull from foundation / hw-foundation — never source paths. One per-feature module, not the whole kit.

02

Prefix discipline

Components Fn* / Hw*; selectors fn-* / hw-*. The prefix tells you the library.

03

Colors from tokens only

Always var(--blue), never #005bc4. New colors extend _variable.scss first.

04

Text through i18n

Every string via the fnTranslate pipe; dates via the global formatter. No hardcoded copy.

05

Forms are reactive

FormGroup + formControlName. HTTP through FnHttpService / HwHttpService.

06

Dark mode = a class

.dark-theme on <html> swaps tokens only. Every routed page uses the .hw-box-content boilerplate.
